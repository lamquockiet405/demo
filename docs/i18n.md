# Ngôn ngữ giao diện

KidMeal hỗ trợ tiếng Việt (`vi`, mặc định) và tiếng Anh (`en`) trên trang chủ, đăng nhập, khôi phục mật khẩu và các cổng ban giám hiệu, dinh dưỡng, giáo viên, bếp, phụ huynh. Chọn **Tiếng Việt / English** trên thanh đầu trang để chuyển ngay tại trang đang mở.

Lựa chọn lưu trong `localStorage` với khóa `kidmeal.language`, được khôi phục khi tải lại và đồng bộ giữa các tab cùng trình duyệt. Đổi ngôn ngữ không khởi tạo lại biểu mẫu, không đổi URL và không xóa phiên đăng nhập. Trình duyệt chặn lưu trữ vẫn cho phép chuyển ngôn ngữ trong phiên hiện tại.

## Cấu trúc

- `apps/frontend/src/core/i18n/language.ts`: quản lý lựa chọn, dịch văn bản hiển thị, định dạng locale và cập nhật thuộc tính HTML `lang` cùng tiêu đề trang.
- `apps/frontend/src/core/i18n/useLanguage.ts`: hook đăng ký cập nhật giao diện mà không remount component.
- `apps/frontend/src/core/i18n/locales/en.json`: bản dịch tiếng Anh, dùng văn bản nguồn làm khóa.
- `apps/frontend/src/core/i18n/locales/vi.json`: nhãn tiếng Việt cho mã trạng thái và những nhãn gốc tiếng Anh.
- `apps/frontend/src/core/components/LanguageSwitcher.tsx`: bộ chọn ngôn ngữ dùng chung, hỗ trợ bàn phím và ẩn khi in.

Các bản dịch được đóng gói cùng frontend; ứng dụng không gọi dịch vụ dịch trực tuyến lúc sử dụng. Thông báo hệ thống/API đã có trong từ điển được dịch tại nơi hiển thị. Văn bản chưa có khóa dịch giữ nguyên nội dung nguồn.

Locale hiển thị là `vi-VN` hoặc `en-GB`. Múi giờ trường học và đơn vị tiền VND giữ nguyên. Biểu đồ, bản in và tiêu đề cột CSV dùng ngôn ngữ đang chọn. Tên người, trường, lớp, món ăn, ghi chú và nội dung tự nhập giữ nguyên; mã trạng thái, ID và giá trị gửi API không đổi khi dịch nhãn.

## Thêm văn bản mới

Đăng ký hook trong component và dịch tại nơi hiển thị:

```tsx
const { t } = useLanguage();
return <button>{t('Lưu thay đổi')}</button>;
```

Thêm khóa tương ứng vào `en.json`, ví dụ `"Lưu thay đổi": "Save changes"`. Với chuỗi động, dùng các vị trí `{{0}}`, `{{1}}` theo thứ tự biểu thức nội suy trong chuỗi nguồn:

```tsx
t(`Menu tài khoản ${user.fullName}`)
// en.json: "Menu tài khoản {{0}}": "Account menu {{0}}"
```

Các giá trị nội suy được giữ nguyên.

Chỉ dịch nhãn giao diện, không dịch giá trị nghiệp vụ hoặc dữ liệu người dùng. Khi dịch `<option>`, luôn khai báo `value` bằng mã gốc để bộ lọc và dữ liệu gửi API ổn định.

## Kiểm tra

```sh
npm --prefix apps/frontend run test:i18n
node --test apps/frontend/tests/*.test.cjs
npm --prefix apps/frontend run build
```

Kiểm thử bao gồm khôi phục lựa chọn, chuyển ngôn ngữ, đồng bộ tab, lưu trữ bị chặn, nội suy, tính toàn vẹn từ điển và giá trị cố định của các lựa chọn biểu mẫu.
